1.1.2 Details Dataset 1

Citation: Glenn Palmer, Vito D’Orazio, Michael Kenwick and Matthew Lane. 2015. The MID4 Data Set, 2002-2010. Conflict Management and Peace Science, 32(2), pp. 222-242.
License: No specific license. Free to use if cited correctly. Users cannot charge for access.
Description: The dataset contains 10,358 observations and 54 variables describing dyadic militarized interstate disputes. It includes identifiers for both states in each dyad, timing variables such as start and end dates, and coded dispute characteristics such as outcome, settlement type, hostility levels, fatality level, revisionist status, and dispute duration. Most variables are numeric codes, while country abbreviations and names are stored as text. Missing data is minimal, with nearly all variables complete and only a small number of missing values.

EDA Report Dataset 1

1.1.3 Details Dataset 2

Citation: Gibler, Douglas M. 2009. International military alliances, 1648-2008. CQ Press.
License: No specific license. Free to use if cited correctly. Users cannot charge for access.
Description: The dataset contains 148,258 observations and 19 variables describing yearly dyadic alliance relationships between pairs of states from 1816 to 2012. It includes country identifiers and names for both states in each dyad, alliance start and end dates, censoring indicators, and coded alliance types such as defense, neutrality, nonaggression, and entente. Most variables are numeric codes or binary indicators, while the two state-name variables are stored as text. Missing data is concentrated mainly in the dyad end-date variables, which likely reflects alliances that had no recorded end date or were still ongoing within the dataset period.

1.1.4 Details Dataset 3

Citation: Barbieri, Katherine and Omar M. G. Omar Keshk. 2016. Correlates of War Project Trade Data Set Codebook, Version 4.0. Online: https://correlatesofwar.org.
License: No specific license. Free to use if cited correctly. Users cannot charge for access.
Description: The dataset contains 886,828 observations and 23 variables describing yearly dyadic trade flows between pairs of states. It includes country codes for both states, the year of observation, importer indicators, bilateral trade-flow measures, smoothed trade values, and indicators for trade spikes or dips. Most variables are numeric, including trade-flow values, binary event indicators, source codes, and version information. The dataset appears complete, with no missing values across the variables.

EDA Report Dataset 3

1.1.5 Details Dataset 4

Citation: Information from the Stockholm International Peace Research Institute (SIPRI) DOI
License: Terms and Conditions
Description: The CSV dataset contains 173 country-level observations and 38 variables showing military expenditure per capita from 1988 to 2024. Each row represents a country, while each year column reports the corresponding per-capita military spending value, with missing values indicating unavailable data or years where figures were not reported. The Excel workbook contains SIPRI military expenditure data organized across multiple sheets, including regional totals, local-currency spending, constant and current US dollar values, military spending as a share of GDP, per-capita spending, and spending as a share of government expenditure. The data covers long-term country and regional military expenditure trends from 1988 to 2024.

1.1.6 EDA Summary

We need only a few of the available variables. Of the relevant variables there are not many that have missing values. Only the trade and milex datasets have a substantial amount of missing data. For those cases, it is not really an issue for the goal of this project. We just need to make sure to declare missing data in the dashboard. One challenge is, that the COW-datasets use their own countrycodes and the milex dataset has the full country names. We will need to map all of them to standardized codes. The Conflict dataset contains a row for each conflict and year. Not just one per conflict. In addition to that this set of rows exists once with Country 1 in the Column State_A and Country 2 in the Column State_B. Then there is the same data with the two countries in switched positions. We have to keep this in mind while creating filters and doing transformations on the data. Furthermore, in some of the datasets there exists data from countries that do not exist today. For simplicity and so that we are able to project the data on a map, we only keep the data for countries that can be mapped to countries that exist today.

1.2 Processed Data

1.2.1 Overview Processed Datasets

All of the data pre-processing is done by the code in the script ./src/import_and_cleaning.py. By executing the script, the raw data is loaded, cleaned and then written to ./data/clean as parquet files. The parquet files are then being loaded by streamlit when the dashboard is started. An easy way to read parquet files is to use the .read_parquet() method from pandas.
